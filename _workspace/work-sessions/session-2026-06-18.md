## Decisions Made

- Why NestGlow section is now a proper client component (`WhyNestGlow.tsx`) rather than inline server JSX — required for carousel state
- Tier `photoSrc` paths are wired in `tiers.ts` but set to `undefined` until photos are physically added to `public/images/tiers/`
- `viewport` must always be exported separately from `metadata` in Next.js 16 layouts — mixing them causes client-side hydration crashes
- Tier card layout: title stays at top, tagline/description push down with `mt-auto` — gives the card a top-anchor + bottom-anchor structure rather than all content stacked at top
- Mobile nav: floating glassmorphism pill dock (light glass, not dark) replaces top SiteNav on mobile. Top nav hidden via wrapper div in layout so desktop is untouched
- Menu opens a compact popover above the dock — not a full-screen sheet — so the dock stays visible and the menu feels contextual
- Popover centering uses `left: calc(50% - 128px)` instead of `translate-x-1/2` to avoid conflicting with the CSS scale animation's `transform` property
- `transform-origin: bottom center` on the popover makes it appear to grow upward from the dock button
